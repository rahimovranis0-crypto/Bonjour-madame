# Бонжур, мадам! — онлайн v1

## Что уже есть
- настоящая серверная комната;
- код приглашения;
- до 3 игроков;
- раздача 36 карт сервером;
- синхронизация ходов через Socket.IO;
- специальные реакции;
- сервер определяет тайм-аут реакции;
- победитель определяется сервером.

## Запуск
1. Установить Node.js.
2. В папке проекта выполнить: `npm install`
3. Запустить: `npm start`
4. Открыть `http://localhost:3000` на трёх устройствах в одной сети (для локального теста).

Для игры через интернет сервер нужно разместить на хостинге с поддержкой Node.js/WebSocket.
